# 物理手弹簧修复（2026-10-17）

工程：`D:/_Programming/Unreal/VRSharp2/VRSharp.uproject`。保留原 VRSharp 的 Weld 抓取方式。

## 修改内容

- 把直接用刚度、阻尼计算力，改为质量归一化的加速度控制；根据有效物理时间步映射连续系统极点，每个游戏帧施加一次冲量。物理子步负责运动和碰撞，不重复反馈。
- 阻尼下限取临界阻尼，防止高刚度、低阻尼和变化帧时间放大振荡。
- 目标位置和旋转差分提供速度前馈，降低持续移动时的滞后；跟踪跳变和长卡顿不作正常速度样本。
- 使用最短四元数旋转向量，处理小角度、q/-q 和恰好 180° 的符号二义性。左右手物理根保持正缩放，仅视觉网格镜像。
- 空手补偿手腕与质心之间的偏移，避免转动手腕引入额外位置摆动。
- Weld 后通过被抓物体的 PrimitiveComponent 访问实际刚体。抓点施加冲量，保留杠杆作用；按驱动方向和偏心杠杆估计抓点有效质量，双手分摊驱动。避免用无关轴的最小惯量削弱整套位置控制。
- 玩家在 PrePhysics 阶段读取控制器，初始化时手放到追踪目标位置，避免从世界原点弹射到控制器。

## 参数与 120 Hz 标定

MCP 读取到旧版左右手实际总质量均为 **5.5479059 kg**，不是根组件里单独显示的 5 kg。碰撞子组件焊接后也贡献质量。

现在左右手各 **0.45 kg**，是用于本工程的合理近似值，并非对所有玩家的精确测量。根组件 0.001 kg、CollisionBox 0.449 kg；PIE 中实际总质量已核对为 0.450000018 kg。

| 设置 | 新值 |
| --- | ---: |
| LocationStiffness（s⁻²） | 427.199127 |
| LocationDamping（s⁻¹） | 41.337593 |
| RotationStiffness（s⁻²） | 397.681244 |
| RotationDamping（s⁻¹） | 39.883892 |
| BodyPullStrength | 5.547906 |

BodyPullStrength 是向玩家身体传力的独立标定系数，不是手的质量。保留它可避免减小手质量后攀爬拉力随之大幅下降。力、力矩上限仍为 80000、800000。

对连续极点速率 a、b，时间步 h 下取 p=exp(-a*h)、q=exp(-b*h)，离散位置增益为 (1-p)(1-q)/h²，速度增益为 (1-pq)/h。结合一次冲量和随后的位移积分，闭环极点就是 p、q。

在 h=1/120 下，位置初始加速度增益等于旧版 2000/5.5479059；旋转以旧惯量三个主值的中位值 23.6988869 kg·cm² 标定，对应旧版 8000/23.6988869。旋转各轴改为归一化响应，因此不再保留旧版各轴不同的强度。

“类似旧版 120 帧”在这里指初始响应强度匹配。旧版欠阻尼的甩动被有意消除，完整轨迹不会与旧版相同。固定时间步的极点匹配也不意味着所有碰撞、限力和变时间步情况下轨迹完全一致。

## 物理配置

已通过 MCP 保存左右手蓝图，关闭手刚体额外线性/角阻尼和重力，开启 CCD，求解迭代为位置 16 / 速度 4。被抓物体自身的重力配置保留。

项目启用同步物理子步：最大子步 1/120 秒，最多 16 步，MaxPhysicsDeltaTime=0.1 秒，异步物理关闭。超过物理时间上限的长卡顿不能模拟成正常追踪。

## 验证与边界

- ManagedVRSharp 编译通过；没有手工复制 DLL，采用 UnrealSharp 自动热重载。
- `Tools/SpringMathChecks` 直接链接生产数学代码，检查 15–240 Hz、不同质量、15/120 Hz 交替且极高刚度、四元数符号和 120 Hz 标定。
- `Saved/Tests/HandSpring-Physics-20261017.json`：12 组实际 Chaos 测试（30/60/90/120 Hz × 0.45/2/5 kg，每组左右手），包含移动、转动、急停和交替 q/-q。全部通过，停稳尾段最大位置误差约 0.047 cm，角度误差约 0.059°。
- 这些测试使用 UE 固定游戏/物理时间步；渲染墙钟帧率可能更低，不能称作 Quest 3 的 120 FPS 实测。
- `Saved/Tests/HandSpring-Grip-20261017.json`：用现有 SpecificGrabCube、真实 GrabWithGrabbable/Release 和 Weld 路径，单手/双手各在 30/120 Hz 验证移动、转动、急停，4 组均通过。被抓物体质量 1 kg，加手后物理岛为 1.45/1.90 kg；尾段最大抓点误差 0.146 cm。这个资产让双手使用同一个预设抓点，因此该测试不能代表分离抓点的全部杠杆和双手冲突情况。
- 测试退出 PIE，恢复固定帧率开关、限帧和后台节流设置；修改测试质量只发生在 PIE，不写回蓝图。MCP 再次核对固定帧率开关已关闭。
- 质量无关响应适用于未达到限力的控制范围。接触、关节、抓取物体质量和力矩上限仍会影响响应。任意资产和任意高参数的非线性接触稳定性没有被证明。
- Quest 3 的实际追踪、碰撞手感、快速转腕和攀爬仍需要用户实测。
